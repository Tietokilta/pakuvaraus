# @tietokilta/pakuvaraus-client

Typed `fetch` client for the pakuvaraus public API. The types in `schema.d.ts`
are generated by [openapi-typescript](https://openapi-ts.dev) from the API's
OpenAPI spec, which is generated from the Rust handlers with
[utoipa](https://github.com/juhaku/utoipa). Requests go through
[openapi-fetch](https://openapi-ts.dev/openapi-fetch/). Neither generated file
is committed.

```ts
import { createPakuvarausClient, type CreateReservation } from "@tietokilta/pakuvaraus-client";

const api = createPakuvarausClient({ baseUrl: "https://pakuvaraus.example" });

const { data, error, response } = await api.GET("/reservations");
await api.POST("/reservations", { body: reservation satisfies CreateReservation });
await api.POST("/reservations/cancel/{edit_key}", { params: { path: { edit_key } } });
```

`error` is typed per status: `ErrorResponse` (`{ error: string }`) for 404, 409
and 500, and a plain-text string for 400 and 422 (axum's body rejections).

## Building

```sh
nix build .#openapi-spec   # result: the OpenAPI spec
nix build .#api-client     # result/: the npm package, ready to publish
```

`nix flake check` builds both, so a handler change that breaks the client's
types fails CI. The running server also serves the spec at `/openapi.json`.

To work on `index.js`/`index.d.ts` locally, in `nix develop`:

```sh
nix build .#openapi-spec -o client/openapi.json
cd client && pnpm install && pnpm run generate && pnpm run typecheck
```

## Releasing

On every push to `main`, after the checks pass, the `publish-client` job in
[`release.yml`](../.github/workflows/release.yml) builds `.#api-client`. When its
contents differ from the latest published version, it publishes the next
patch version with trusted publishing. It takes major and minor from
`version` in `package.json`, and ignores the patch there.
For a breaking API change, bump the minor version (or the major after 1.0) in
`package.json`, since `^0.1.0` only accepts new `0.1.x` patches. The npm
package's settings must list `release.yml` as a trusted publisher that is allowed to
run `npm publish`.
